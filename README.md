# ZEN · compañero de Codex para Windows

ZEN reúne la actividad de Codex, el sonido de Windows, los avisos y Apuntes en una sola cápsula. En Inicio puedes enviar peticiones al chat fijado y consultar Gmail o Google Calendar a través de Codex.
