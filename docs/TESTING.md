# Pruebas de ZEN

**Contraseñas.** `tests/password-vault.test.ts` prueba cifrado de todos los campos, servicios repetidos, edición conservando la clave, reinicio bloqueado, maestra incorrecta y archivo dañado sin sobrescritura, fallo de escritura y revocación durante KDF. `tests/companion-vault.test.ts` verifica sesiones revocadas, vista y foco, copia sin devolver secretos y temporizador de revelado. `node scripts/vault-windows-smoke.mjs` usa Electron con perfiles temporales y una aplicación WinForms separada para el pegado real y las consultas de portapapeles/historial de Windows; no usa cuentas personales. Guarda resultados y capturas ficticias en `release/vault-acceptance/`. El evento `lock-screen` se inyecta en esta prueba; el bloqueo físico de Windows y el recorrido manual de Win+V se verifican aparte, sin cambiar la configuración de privacidad del equipo.

El 20 de noviembre de 2026 pasó la aceptación automatizada: dos cuentas del mismo servicio, máscara fija, una sola clave visible, límite de diez segundos, ocultamiento por foco, pegado en WinForms tras replegar, las tres marcas privadas de Windows, historial activado sin la clave, conservación del texto posterior, limpieza a treinta segundos, rechazo de maestra errónea sin cambiar el archivo y reinicio bloqueado con recuperación de ambas cuentas. El bloqueo por evento de Windows se probó mediante inyección, no bloqueando físicamente la sesión.

La entrega pasó 680 pruebas en 72 archivos, build de producción y auxiliares, recorrido del paquete Windows y recorrido del portable extraído. Se compararon los hashes de main y del auxiliar de portapapeles del build probado con los del paquete. Se corrigió la toma de secuencia del portapapeles: debe hacerse después de `CloseClipboard`, porque Windows añade formatos derivados al cerrar; la limpieza comprueba también el HWND propietario. El informe de Contraseñas está en `release/vault-acceptance/result.json` y el de arranque portable en `docs/evidence/single-executable.json`.

## 01 · Capas de verificación ![](assets/violeta.svg)

| Capa | Comando | Alcance |
| --- | --- | --- |
| Unitarias | `npm test -- --maxWorkers=4` | Esquemas, reglas de visibilidad, peticiones, almacenamiento y casos de error. |
| Tipos y producción | `npm run build` | Ejecuta TypeScript sin emitir y construye main, preload y renderer. |
| Auxiliares | `npm run build:native` | Compila los proyectos del manifiesto de Windows, incluidos el portapapeles y Windows Hello de Contraseñas. |
| Electron | `npm run test:electron` | Recorrido de la ventana, IPC y funciones del compañero con un perfil temporal. Requiere bundles y auxiliares compilados. |
| Portable | `node scripts/single-file-smoke.mjs release/single-file/ZEN.exe` | Comprueba extracción, arranque y recorrido del ejecutable concreto. |

El repositorio carece de un script de lint separado. Los comandos históricos de API y agente tienen otro alcance. Para la entrega del compañero usa el recorrido de Electron y el portable según [Despliegue](DEPLOYMENT.md).
