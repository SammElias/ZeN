# Guía de trabajo para agentes

El [AGENTS.md raíz](../../AGENTS.md) sigue siendo la autoridad de este repositorio. Este archivo indica cómo usar el blueprint dentro de esta carpeta; no sustituye reglas operativas ni autoriza efectos sobre el equipo o servicios.

1. Ubica el cambio en [Producto](PRD.md) y [Flujos](UX_FLOWS.md). Consulta [Arquitectura](ARCHITECTURE.md), [IPC](API.md) y [Seguridad](SECURITY.md) si atraviesa procesos o maneja datos privados.
2. Contrasta con el código activo y con las instrucciones del usuario. Si un documento histórico describe otro comportamiento, identifica la diferencia y actualiza la referencia vigente cuando corresponda.
3. Conserva cambios ajenos. Acota los archivos que necesitas, respeta los contratos y usa datos sintéticos para verificar.
4. Ejecuta las comprobaciones pertinentes de [Pruebas](TESTING.md). Distingue evidencia automatizada, comprobaciones físicas y límites pendientes.
5. Actualiza los documentos afectados y el mapa si cambian sus piezas o relaciones. Compilar, reemplazar un ejecutable y publicar son acciones distintas; sigue el alcance autorizado.
