# Cambios

Este registro resume cambios observables del compañero. La versión del manifiesto se mantiene en `0.1.0`; una fecha aquí no implica publicación.

## 2026-11-11 · Trabajo local

- Home permite enviar peticiones a la cola del chat fijado. Sin destino configurado, prepara un borrador en Codex.
- El flujo activo delega correo y agenda en Codex. Se retiran sus paneles directos del compañero.
- Resumen presenta la última respuesta final como Markdown, con tablas, listas y bloques de código, y recupera el historial local cuando corresponde.
- Home actualiza su diseño de cristal. Sonido sustituye el nombre de Spotify y sigue automáticamente las sesiones que publica Windows.
- Se añade el blueprint de documentación y el mapa HTML de Archify. Este cambio documental no modifica el ejecutable.

## 2026-11-04 · Revisión `0b0f2b4`

La revisión registrada en Git incorporó la ventana redimensionable, ajustes Liquid Glass, apariencia de cápsula guardada y las integraciones Google de aquella etapa. Los dos paneles de Codex y la cápsula se mantienen; las integraciones directas de Google se describen únicamente como histórico en el corte actual.
