# Publicación de ZEN — 23/10/2026

El usuario solicita subir ZEN a GitHub y después autoriza retirar la imagen de Coucou, dejando la creación de un personaje propio para el futuro.

La cápsula activa muestra un monograma Z. Se retiran el personaje, vestuario y seguimiento periódico del cursor. Los iconos de aplicación y bandeja proceden de un SVG original, generado por `scripts/app-icons.mjs`; los avisos utilizan tonos propios sintetizados localmente. Estados, chat/proyecto fijados, permisos de un uso, atajos, silencio y notificaciones conservan su comportamiento.

Solo se adapta y publica código MIT de Coucou con su atribución. Su personaje, dibujo procedural, iconos, sonidos y medios tienen licencia separada; permanecen como material local inactivo e ignorado. La publicación excluye `src/coucou/mochi/engine.ts`, `src/coucou/mochi/outfits.ts`, `public/coucou-sounds/`, `public/icons/coucou-source.png`, el kit de mascota y sus archivos comprimidos. Tampoco se empaquetan estos recursos. El componente histórico `CoucouMochi.tsx` conserva únicamente una marca neutra para compatibilidad con fuentes inactivas.

Las configuraciones históricas de agente y Live se conservan sin modificar. No se reinstalan hooks ni se cambia confianza para retirar el personaje. No se altera el chat de Codex ni se envía trabajo nuevo.

Los informes, capturas, perfiles y configuración del chat fijado son datos locales. Las nuevas evidencias de pruebas se guardan fuera del conjunto publicado. Los informes ya versionados se conservan como históricos; no se presentan como validación reciente.

La publicación contiene fuentes, pruebas, documentación, iconos propios y licencias de código. No publica el EXE que contenía recursos de Coucou ni crea una release. El EXE local actualizado se entrega únicamente en el escritorio, con respaldos dentro de `release/`.
